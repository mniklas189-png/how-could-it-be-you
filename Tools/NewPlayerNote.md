**Neu dabei?**

- Unten unter „Assets“ **HCIBY-Launcher.zip** herunterladen, entpacken und **HowCouldItBeYouLauncher.exe** starten. Der Launcher installiert das Spiel und hält es aktuell. Linux: HCIBY-Launcher-Linux.tar.gz, die Anleitung liegt bei.
- Windows warnt beim ersten Start („Der Computer wurde durch Windows geschützt“), weil das Programm nicht signiert ist. Klick auf **Weitere Informationen** → **Trotzdem ausführen**. Das kommt nur einmal.
- Wer eine Lobby hostet, wird von der Windows-Firewall gefragt, ob das Spiel ins Netzwerk darf: **Zugriff zulassen**, sonst kann niemand beitreten.

## English

**New here?**

- Download **HCIBY-Launcher.zip** from "Assets" below, unzip it and start **HowCouldItBeYouLauncher.exe**. The launcher installs the game and keeps it up to date. Linux: HCIBY-Launcher-Linux.tar.gz, the guide is inside.
- Windows warns on the first start ("Windows protected your PC") because the program is not signed. Click **More info** → **Run anyway**. It only asks once.
- Whoever hosts a lobby gets asked by Windows Firewall whether the game may use the network: click **Allow access**, otherwise nobody can join.
